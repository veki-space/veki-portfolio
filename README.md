# Likhitha portfolio (React + Vite)

    npm install

    npm run build     # outputs /dist, deploy to Vercel/Netlify/GitHub Pages

Edit all content in `src/data.js`.
Put your `resume.pdf` in the `public/` folder.
Replace the placeholder email, LinkedIn, GitHub and project GitHub links in `src/data.js`.
